# Guia de build SinX

## Introdução
Classe de dano extremamente versátil, excelente contra alvos únicos, mas também consegue limpar grupos de monstros (AoE) de forma decente.  

Possui muitas opções de equipamentos, então montar a build é relativamente fácil. A única desvantagem é que você precisará gastar zeny ou tempo farmando materiais para venenos a fim de maximizar seu potencial.

Este guia não é um guia definitivo sobre como buildar ou jogar com essa classe, mas deve ajudar as pessoas a encontrarem respostas para dúvidas frequentes e entenderem como jogar de SinX.

Se você tiver informações mais atualizadas ou melhores, por favor me avise no canal de SinX do MoY no Discord ou me mande uma DM para @asfaras.

## Builds

O que você escolher pegar na primeira classe é mais questão de preferência pessoal, mas vou compartilhar o que considero boas opções no geral para qualquer build. 

### Gatuno Skills

![][image1] **Improve Dodge - 10**
Sempre maximize. Concede tanto esquiva quanto velocidade de movimento, algo muito bem-vindo em qualquer build.

![][image2] **Envenom \- 10**  
Necessário para Poisonery e Advanced Poison Mastery. Pode ser ignorado caso esteja upando com build física e pego depois com reset de habilidades. 

![][image3] **Steal \- 4 / x**  
4 pontos são necessários para Hiding. Você pode maximizar se quiser, mas não usará muito Steal mais pra frente. Especialmente em builds de crítico, já que você terá pouca DEX. 

![][image4] **Hiding \- 1 / x**  
1 ponto é necessário para Cloaking. Você pode optar por maximizar se quiser. 

![][image5] **Sprinkle Sand \- 10 / 0**  
Excelente até virar Assassin Cross caso pretenda upar como thief físico. Pode ficar em 0 após reset de habilidades. 

![][image6] **Throw Stone \- 0 / 10**  
Muito bom para matar monstros low level e interromper conjurações depois de virar Assassin Cross, mas eu não pegaria durante o leveling. 

![][image7] **Double Attack \- 10**  
Se você pretende usar ataques básicos em qualquer momento, maximize esta habilidade.

### AA Critical & Meteor Assault (Híbrido)
![][image8] **Dual Wield Mastery \- 10 / 0**  
Obrigatório para builds de dual wield. Também é bom ter mesmo se você pretende jogar principalmente de katar. 

![][image9] **Katar Mastery \- 10 / 0**  
Obrigatório para builds de katar. Também é bom ter mesmo se você pretende jogar principalmente de dual wield. 

![][image10] **Cloaking \- 2 / 10**  
Mínimo de 2 pontos. Maximizar é ótimo pela velocidade de movimento, mas consome muitos pontos de habilidade que poderiam ser usados em outro lugar. Se tiver certeza de que nunca vai jogar de Sonic Blow, pode maximizar. 

![][image11] **Grimtooth \- 5 / 0**  
Pré-requisito para Sonic Blow. Não é recomendado usar. 

![][image12] **Sonic Blow \- 0 / 10**  
Não existem muitas builds de Sonic Blow, mas se você não maximizar Cloaking pode pegar essa habilidade para upar ou apenas para ter a opção de jogar de Sonic Blow no futuro. 

![][image13] **Enchant Poison \- 5**  
**Obrigatório maximizar** para Poisonery e Advanced Poison Mastery. Use no nível 4\. 

![][image14] **Poisonery \- 1 / 5**  
1 ponto é obrigatório para Advanced Poison Mastery. Recomenda-se usar serviço de brewer/alquimista. 

![][image15] **Meteor Assault \- 10 / 0**  
Só pode ser usado com dual wield (sem katar), mas é extremamente forte. 

![][image16]**Cross Lethality \- 10**  
**Obrigatório maximizar.** Aumenta o dano de katar e a taxa de crítico no dual wield. 

![][image17] **Advanced Poison Mastery \- 5**  
**Obrigatório maximizar.** Necessário para usar Deadly Poison. 

![][image18] **Soul Destroyer \- 0 / 10**  
Mesmo em builds com apenas 1 de INT, pode ser uma boa opção se você montar equipamentos em volta da habilidade. 

## Atributos

* STR no começo > AGI no late game  
* Builds AA querem alcançar 191 de ASPD  
* DEX para Meteor Assault  
* LUK concede ATK, HIT e Crit

As builds de crítico e Meteor Assault são bem parecidas, facilitando alternar entre elas.  
 Builds AA precisam de mais AGI para alcançar 191 ASPD e um pouco de LUK para crítico.

 **Exemplo de build final AA Katar/Dual Wield Crit** 

| Atributo | Valor | Observação |
| ----- | ----- | ----- |
| STR | 50–80 | *Principalmente por capacidade de carga e dano no early game* |
| AGI | 90–100 | *Objetivo é alcançar 191 ASPD* |
| VIT | x |  |
| INT | x |  |
| DEX | x | *Principalmente para Meteor Assault e brewing* |
| LUK | 30–60 | *Apenas o suficiente para atingir 110–120 de crítico* |

**Exemplo de build final Meteor Assault** 

| Atributo | Valor | Observação |
| ----- | ----- | ----- |
| STR | 80–100 | *Dano e capacidade de carga* |
| AGI | 60–90 | *Apenas para flee* |
| VIT | \+50 | *HP e redução da duração de stun* |
| INT | x |  |
| DEX | 1–40 | *Para taxa de acerto caso o HIT% não seja suficiente* |
| LUK | 1–10 | *Pequeno aumento de ATK e HIT* |

É possível jogar de Dual Wield Crit e apenas sacrificar um pouco de STR por DEX, além de pegar HIT% no alinhamento estelar para fazer uma build híbrida de Meteor Assault.

Katars têm potencial para causar um dano absurdo em alvo único graças ao efeito de reforge, mas não possuem a capacidade de usar Meteor Assault para limpar grupos de monstros em área (AoE).  

Ainda existe debate sobre qual causa mais dano: Katar ou Dual Wield.

## Armas
**ATK da arma \> todo o resto.**  
O ATK da mão principal é o que mais importa. Katars e espadas precisam de uma carta Sidewinder ou Snake Hat.

Para builds de Meteor Assault, utilize a espada com maior ATK (contra médios) ou machado (contra grandes).

Do melhor para o pior em builds AA (qualquer uma dessas com bons rolls de singularidade já é considerada boa): 

| Melhor | ---- | ---- |----| ---- | Pior | 
| ----- | ---- | ---- |----| ---- | ---- |
| Durga\[1] | Scapel\[3] | Desert Twilight\[3] | Kamaitachi | Gladius\[3] | Stilleto\[3] |

O ATK da mão secundária também importa para builds AA. Espadas possuem uma penalidade de ASPD levemente maior.

Para builds de Meteor Assault, use qualquer opção de 4 slots com: 3x cartas de raça/elemento \+ 1x carta de tamanho ou 4x Wolf Card.

Do melhor para o pior em builds AA (qualquer uma dessas com bons rolls de singularidade já é considerada boa):

| Melhor | ---- | ---- |----| ---- | ----| ---- | Pior | 
| ----- | ---- | ---- |----| ---- | ---- | ----| ---- |
| Scapel\[3] | Gladius\[3]  | Tsurugi\[3] | Platinum Shotel\[1] | Flambergue\[2] | Stilleto\[3] | Sandstorm\[4] | Kitchen knife | 

### Singularidades recomendadas

Do melhor para o pior — mas pegue o que sua build precisar.

* VCT fixo  - *recomendado 1 roll para Meteor Assault*  
* ASPD% / ASPD fixa  - *para builds AA*  
* Dano Crítico% \> CRIT  - *para builds AA*  
* ATK% \> ATK fixo  - *ATK fixo apenas para a arma principal*  
* Ignore DEF - *DEF Pierce*  
* HIT  - *para builds de Meteor Assault*

## Star Alignment

**Estrelas Pequenas**

Flee% ou AGI / ASPD% - *ASPD para builds AA*
Recuperação de SP / HIT%  - *para builds de Meteor Assault*

**Estrelas Grandes**

* CRIT / ASPD / Flee% / AGI - *para builds AA*  
* HIT% / Recuperação de SP - *para builds de Meteor Assault*

**Estrela Cintilante**

* AA Builds: Critical Edge / Berserker's Fury / Omni Agility  
* Veil of Evasion / Omni Strength

## EDP

Concede \+25% de ATK e um multiplicador de 4x no seu dano.

Você pode usar o serviço de um Creator para criar Karvodailnirol com matérias-primas ou comprá-lo diretamente. Também recomendo procurar um SinX full craft para serviço de Poisonery, maximizando o rendimento do EDP.

Pode acabar ficando caro, mas quando você estiver forte o suficiente para farmar áreas com drops valiosos, vale muito a pena usar.
